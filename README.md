# robotics-lab 🤖

### My journey from software engineering to robotics, autonomous systems, and embodied AI.

I'm a software engineer with a background in backend and systems development, now exploring how software can move beyond servers and screens and into the physical world.

This repository is where I learn, experiment, build, break things, and document that transition.

---

## 🎯 Why Robotics?

I've spent the last few years building software systems.

Now I want to understand something different:

> **How do we build software that can perceive the physical world, make decisions, and act in it?**

That leads to robotics, autonomous systems, and eventually embodied AI.
